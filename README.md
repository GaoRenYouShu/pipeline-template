# pipeline-template

一套 AI 协作开发的流程模板：多仓备份、fail-closed 发布、独立评审、工程度量。最初为多会话并行的工作方式设计，单人项目也能用。

内容都在 SKILL.md 里：核心原则，十三件标准件（判据、接口、实现要点、验收），新项目接入顺序，运行纪律和已知风险。一份文件，不依赖别的仓库。

## 使用

支持技能机制的工具（比如各类 AI 编码助手）：把 SKILL.md 放进它的技能目录，位置看工具自己的说明。

其他情况把它当规格文档读，按 SKILL.md 第八节的顺序在项目里逐件实现。每件都写了验收标准，做到即完成。
